    Connect your GE100 Pro

    1. Plug the pedal's data USB-C port into this computer. The other port only charges.
    2. Close Mooer Studio: only one program can talk to the pedal at a time.
    3. Click Connect pedal and pick the GE100 Pro in the browser's list.

    Selecting presets and turning knobs changes the sound right away but is not stored. Only Save writes to the pedal, and it always asks first. This editor is unofficial and not made by Mooer.

    This browser can't talk to USB devices. Use Microsoft Edge or Google Chrome, and open the page from disk or from http://localhost.
